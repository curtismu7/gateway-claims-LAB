# gateway-claims-LAB

Demo-tier standalone app (Tier: Demo, catalog D99): what the Privilege gateway (mcpgw) versions added, shown in MOCK only. Tabs: (1) nested-claim gate (v1.261024: a mock PingFederate-style token with an object `act.sub`, a mock Privilege rule with RequiredClaims `client_id` + `act.sub`), (2) v1.261027 scope gates (Cedar scope gate with the Active-vs-candidate trap, the PingFederate `resource=` parameter, RequiredClaims scope tiers; measured live 2026-10-27, values invented), (3) v1.261028 AgentCore (read from a binary diff, INFERRED, never run), (4) v1.261029 + v1.261030 (readings of two newer images and the 2026-11-02 features NOT measured; all UNVERIFIED, text only), (5) On-behalf-of (RFC 8693 mock engine, 13 scenarios) and (6) AgentCore console (one modelled gateway per workspace, six actions, three probes, computed 12-check scorecard), (7) AgentCore posture (shape only), (8) Diagram, (9) Talk track. Ping release claims are UNVERIFIED on our tenant; every row is tagged.

- Run: `./scripts/run.sh` (http://localhost:5150). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest; scripts). Preflight: `npm run doctor`. Reset: `npm run reset`. Docker: `HOST_PORT=5150 docker compose up --build -d` (127.0.0.1 only). Node 26 only.
- Modes: **Mock only.** The header has a Mock | Live toggle on every page; Live is refused with an honest message (`NO_LIVE` in `releaseClaims.js`, sent as `liveRefusal` by `GET /api/info`) and the page stays in mock. `GCLAB_MODE=live` stops the server and fails the doctor. There is no Live engine: do not add one without the owner.
- Settings: the one shared file `~/Development/.env` (or `STANDALONE_ENV`), parsed with `util.parseEnv` in `server/src/settings.js`; the only key taken is `GCLAB_MODE`. Never a bare `MODE`, never a per-app `.env` loader.
- Core: `server/src/claims.js` (pure `evaluateClaims`, `flattenClaims`, bounded). Story data `claimsData.js`, `postureData.js`, `latestData.js` with `{{castBrand}}`-style tokens filled by `cast.js` (3 vertical packs); a test fails on an undefined token. Diagrams: `server/diagrams/*.json` (diagram-studio/1, loaded by name by `diagramData.js`).
- API: `GET /api/scenarios`, `POST /api/evaluate`, `GET /api/scope-gate`, `POST /api/scope-gate/evaluate`, `GET /api/agentcore`, `POST /api/agentcore/evaluate`, `GET /api/latest`, `GET/POST /api/obo...`, `/api/agentcore-console...`, `GET /api/posture`, `GET /api/diagram`, `GET /api/runs`, `POST /api/reset`, `GET /api/info`, `GET /api/health` (demo-health/1). Workspace id in `X-Workspace`.
- Typed text, ALL endpoints: the custom token is masked on the way out (`maskTypedDeep`), a credential-looking scope is refused (`credential_like`), every answer goes through `maskDeep`; `masking-existing.test.js` and `masking.test.js` are the sweeps. A fixed lab text must not read as an assignment (`token:` followed by a word): reword it (`latest.test.js` pins the new tab).
- Generated files: change the engine or the data, then `npm run mock-table`, `npm run talk-track`, `npm run content-pack`; tests fail on drift. Web banner text is pinned to `releaseClaims.js` by a repo test.
- Web: `web/src/App.jsx` (tabs, Mock|Live toggle, presenter, Reset, X-Workspace via `workspace.js`). UI: `web/src/styles/standalone-ui.css` vendored byte-for-byte from AI-DEMO-Standalone (never edit it); `app.css` is layout only, tokens only (check with `bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`). Run buttons use `ActionButton` (aria-disabled, focus kept). Diagram: `PatternDiagram` + `hooks/useDiagramStepper`.
- Rules that bite: loopback bind only; same-origin writes; zero outbound network (netguard incl. UDP connect, with a self-test); only `.example`/`.invalid` hosts; fake ARNs use account 000000000000; no EC key generation by `generateKeyPair`; ports 5150-5199; say "P1 Privilege Agent App", never "door"; tokens are mock-issued and shown raw; no k8s or SE build (deferred by the owner); no identifiers from other projects.
- Claims status: "nested matching is new in v1.261024" is an INFERENCE from binary symbols: UNVERIFIED. The posture panel is "Shape only - field values invented - UNVERIFIED against the real product". Nothing from the 2026-11-02 release is verified.
- Run check-drift, check-css and conformance by hand (they are not in this repo's CI). Catalog id D99 was confirmed by the owner on 2026-10-28.
